list-poems:

STARTHELP

Description:

    List the poems in the specified configuration

Arguments:

    - (string) Name of the configuration
    - (flag) --detailed: show full details (uuid, filepath) for each poem.
      If omitted, only dates and titles are shown.

Usage:

    list-poems [configuration-name] [--detailed]
    lsp [configuration-name] [--detailed]

ENDHELP
