add-poem:

STARTHELP

Description:

    Add a poem to the specified configuration

Arguments:

    - (string) Name of the configuration
    - (string) Path to the poem file to add (relative or absolute). This path is
      stored as-is and used later by generate-html to locate and copy the source
      file, so it should remain valid from the tool's working directory.

Usage:

    add-poem <configuration-name> <poem-file-name>
    addp <configuration-name> <poem-file-name>

ENDHELP
